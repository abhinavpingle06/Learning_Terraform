What is a Backend?

A Terraform backend determines where Terraform stores its state file. This file tracks resources managed by Terraform, including EC2 instances, ECR repositories, and security groups.

Amazon S3

AWS • Recommended

Stores shared state in S3 with optional state locking.

backend "s3"

Recommended for AWS CI/CD

For a Jenkins pipeline deploying Docker images from ECR to EC2, an S3 backend provides centralized Terraform state. 

terraform {
  backend "s3" {
    bucket       = "your-state-bucket"
    key          = "jenkins/terraform.tfstate"
    region       = "ap-south-1"
    encrypt      = true
    use_lockfile = true
  }
}

Note: Create the bucket first. Enable bucket versioning, block public access, and configure IAM permissions. Use a Terraform CLI version that supports S3 lockfiles.
